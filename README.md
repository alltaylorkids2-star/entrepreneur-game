ENTREPRENEUR: Make It or Go Broke
A one-file-folder browser tycoon for an entrepreneurship class.

You start with a job, not a pitch deck. Rent hits. What’s left is savings. When the bar fills, you open a shop. Then it’s a company — ads, people, prices, debt, luck — until you make it or go broke.

Fun first. The ideas show up because the numbers bite, not because a quiz asked.

Open it
No install. No account. No server.

Download or clone this folder.
Open 
index.html
 in Chrome, Edge, or Firefox.
That’s the game.
Works offline after the fonts cache. Progress saves in the browser (localStorage). Clearing site data wipes the run.

Bash

python3 -m http.server 8080
Then visit http://localhost:8080.

How a class session goes
The first chapter is three choices. Name. Job. Housing. Lifestyle starts Tight on purpose.

Then the loop is one gold bar that says DO THIS:

Get a paycheck.
Work a month. Rent comes out. Keep the leftover.
Open a cheap shop when you can afford it.
After that, run the company. One button still closes the month.
Don’t lecture during play. After Retire / End run, the game writes the story: cash flow, leverage, dilution, concentration, the vest.

Space or Enter advances a month. Esc closes a panel.

What’s in here (so you can talk about it)
In the game	In the room
Job → savings rate → first shop	You fund a venture from wages
Tight vs Splash	Lifestyle is a burn rate you chose
Price: value / standard / premium	Volume vs margin
Ads, hires, upgrades	Spend to earn — or just spend
Loans & credit	Leverage is a tool and a weapon
Investors / Series A / buybacks	Dilution is real
Markets, rivals, contracts	Luck is loaded, not a lottery
Bankruptcy recovery	Failure is an intermission
21 business types. A grocery vest if you need to start over.
